When you delete a project it goes to **Trash**, so an accidental deletion no longer means reaching out to support. You can restore it yourself.

## Deleting a project

Open the project, then use the project menu in the top-right and choose **Delete project**. The project moves to Trash instead of being removed straight away.

## Restoring a deleted project

1. Open **Trash** from the workspace sidebar.
2. Find the project you want back.
3. Click **Restore project** to return it to the workspace.

<Callout status="info">
Deleted projects stay in Trash for 30 days, after which they're permanently removed.
</Callout>
