To export a notebook as a `.ipynb` file, right-click the notebook in the left `Notebooks` list, choose `Export as ...`, and select `.ipynb`.

<VideoLoop src="../assets/docs/export-notebook/export-notebook-ipynb.webm" />

If you need a static version to share or print, you can also [export ipynb as PDF](https://deepnote.com/docs/export-pdf) directly from Deepnote, either with or without code cells.
