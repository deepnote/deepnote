Creating an app is a great way to present your story in a more polished way, while enabling multiple users to simultaneously use the app without interfering with one another. Build one as a [data app project](/docs/data-app-projects), a custom HTML page backed by a notebook, or as a [Streamlit app project](/docs/streamlit-app-projects). [Choosing how to build an app](/docs/playbook-choosing-an-app-type) compares them. Apps published from notebook blocks ([Data apps](/docs/data-apps)) are deprecated.
