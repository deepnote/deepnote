Deepnote is a workspace for data analysis with Python, SQL, and no-code tools. Connect your data, work with teammates, use AI assistance, and publish notebook results as dashboards or apps.

## Use Deepnote to

### Analyze with AI

- [**Describe and visualize:**](https://deepnote.com/docs/ai-data-visualization) Generate visualizations and code by describing your goal.
- [**Auto AI:**](https://deepnote.com/docs/deepnote-ai) Write, execute, and debug code with AI.
- [**Deepnote Agent:**](https://deepnote.com/docs/deepnote-agent) Delegate multi-step data tasks to a sidebar agent that can create and edit blocks, run code, and inspect outputs.
- **Code completion:** Use context-aware code suggestions as you type.

### Unify

- [**Connect data:**](https://deepnote.com/docs/integrations) Integrate with more than 60 data sources, including BigQuery, Snowflake, and PostgreSQL.
- **Combine Python and SQL:** Use both languages in the same notebook.
- [**Reuse modules:**](https://deepnote.com/docs/modules) Build reusable components for ETL processes, analytics, and trusted metrics. Write them once and reuse them across projects.
- [**Define a semantic layer:**](https://deepnote.com/docs/semantic-layer) Share reusable definitions and metrics across your organization.

### Scale

- **Choose a machine:** Select the compute resources that your project needs.
- [**Schedule and notify:**](https://deepnote.com/docs/scheduling) Schedule notebook runs and receive notifications about their results.
- [**Work in a team:**](https://deepnote.com/docs/real-time-collaboration) Organize analyses in projects and folders that your team can share.
- **Integrate via REST API:** Manage projects, notebooks, and workflows through the API.

### Launch

- [**Publish:**](https://deepnote.com/docs/data-apps) Turn notebooks into dashboards or data apps, or use the [Streamlit integration](https://deepnote.com/docs/streamlit).
- **Add inputs:** Let viewers filter data and test different values.
- **Share:** Control who can open your apps.
