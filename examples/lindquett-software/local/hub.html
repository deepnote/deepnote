Choosing an app type

How each one is built

  1. Ask a coding agent with the Deepnote skill (deepnote install-skills) for the notebook, and run it with node local/run.mjs <app>.
  2. Build the page in <app>/app/ and try it here, against the same notebook.
  3. Push the notebook to Deepnote, then deepnote publish local/build/<app>/site --create "<name>".
